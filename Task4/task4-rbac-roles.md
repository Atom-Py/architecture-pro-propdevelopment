# Роли для доступа к Kubernetes

| Роль | Права роли | Группы пользователей |
| --- | --- | --- |
| `cluster-admin` (встроенная ClusterRole) | Все действия со всеми ресурсами кластера. Привилегированная роль для аварийного доступа и обслуживания платформы | `propdev:cluster-admins` - администраторы платформы Kubernetes, один-два DevOps-инженера |
| `propdev-security-auditor` (ClusterRole) | Чтение всех ресурсов во всех namespace, включая secrets, роли и привязки RBAC, события. Изменения запрещены. Привилегированная роль | `propdev:security` - специалист по ИБ |
| `propdev-secrets-manager` (ClusterRole, выдаётся через RoleBinding в namespace домена) | Просмотр, создание, изменение и удаление secrets только в namespace своего домена: `sales`, `housing`, `finance`, `data`. Привилегированная роль | `propdev:sales-devops`, `propdev:housing-devops`, `propdev:finance-devops`, `propdev:data-devops` - DevOps-инженеры продуктовых команд домена |
| `propdev-cluster-configurator` (ClusterRole) | Настройка кластера: namespaces, resourcequotas, limitranges, networkpolicies, storageclasses, ingressclasses, priorityclasses, poddisruptionbudgets, persistentvolumes, изменение узлов (метки, taints, cordon). Просмотр рабочих нагрузок, масштабирование deployments и statefulsets, перезапуск подов. Не создаёт рабочие нагрузки, нет доступа к secrets, RBAC и exec | `propdev:devops` - DevOps-инженеры продуктовых команд |
| `propdev-namespace-developer` (ClusterRole, выдаётся через RoleBinding в namespace домена) | В namespace своего домена: создание и изменение deployments, statefulsets, jobs, cronjobs, services, configmaps, persistentvolumeclaims, ingresses, horizontalpodautoscalers, poddisruptionbudgets, просмотр и удаление подов, чтение логов, просмотр сетевых политик. Secrets подключаются к подам через манифесты, но через API не читаются. Нет доступа к exec, port-forward, RBAC и другим namespace | `propdev:sales-developers`, `propdev:housing-developers`, `propdev:finance-developers`, `propdev:data-developers` - разработчики и инженеры по эксплуатации продуктовых команд домена |
| `propdev-cluster-viewer` (ClusterRole) | Только просмотр (get, list, watch) рабочих нагрузок, сервисов, конфигурации, узлов, namespace и событий во всём кластере. Нет доступа к secrets, логам подов и exec | `propdev:viewers` - владельцы продуктов и бизнес-аналитики |
